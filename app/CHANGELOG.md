# 更新记录

## 0.1.7

- 单图预览按当前窗口区域选择目标尺寸，不再默认为每张照片生成固定 4096 像素预览。
- 打开单图时先显示已有或快速生成的缩略图，再加载窗口尺寸的清晰预览。
- 单图解码进入高优先级队列，切换到单图时取消排队的网格缩略图任务。
- 图片缓存按目标尺寸区分，窗口大小变化时可以保留并复用已有结果。

## 0.1.6

- 网格 JPG 优先读取 EXIF 内嵌缩略图，避免为小预览解码整张高像素原图。
- 没有内嵌缩略图时，使用无 Cgo 的 `jpegn` 在 JPEG 解码阶段按 1/2、1/4 或 1/8 缩小，再生成网格预览。

## 0.1.5

- 记住照片信息侧栏和顶部工具设置栏的展开状态，下次启动恢复上次设置。
- 按钮、快捷键和 Esc 收起操作都会即时保存状态。

## 0.1.4

- CI 仅保留 macOS 和 Windows 检查，移除 Linux 检查及其渲染依赖安装，减少发布等待。
- 保留 Linux 安装包构建与签名更新；构建机已有 NSIS 时跳过重复安装。

## 0.1.3

- 单图大图模式增加左右边缘切换区域：鼠标靠近边缘时显示大箭头，点击整列即可切换上一张或下一张。
- “100% 显示”改为“适合窗口”，点击后按当前屏幕显示区域完整适配图片。
- 筛选后清理已经不可见的缩略图和大图缓存；筛选或排序变化时取消旧的待解码任务，让新显示区域优先加载，并保留可复用的已完成缓存。

## 0.1.2

- 网格工具栏增加缩略图增大、减小和复原按钮，调整后自动重新排列。
- 支持 Ctrl + 滚轮调整缩略图大小：向上增大、向下减小；普通滚轮继续滚动列表。
- 调整大小保留选中照片并复用已有缩略图缓存，复原恢复默认大小。

## 0.1.1

- 单图视图支持双击返回网格，并保留当前选中的照片。
- 增加放大、缩小、100% 预览像素显示与恢复适应窗口。
- 支持鼠标滚轮、触控板捏合缩放，以及拖动或双指滚动平移。
- 按住 Ctrl 拖出矩形，松开后放大选中区域。
- 支持 `+` / `-` 缩放、`0` 恢复默认视角；切换照片时自动复位。

缩放目前使用最长边 4096 像素的预览，放大时尚未重新解码原图。本次未调整目录加载流程。

## 0.1.0

首次公开版本。

- 极简单图浏览与缩略图网格，支持打开文件夹、左右切图、双击或 Enter 打开照片。
- 照片信息侧栏显示 ISO、快门、光圈、相机和常用 EXIF；按照片方向自动转正。
- 提供 11 种排序、文件名搜索、后缀快捷筛选、仅 RAW 和 ISO 范围筛选。
- 支持常见位图，以及 RAW 内嵌 JPEG 预览；macOS 可回退到系统 RAW 解码。
- 接入中文原生更新窗口、每日检查和签名更新；安装新版前会校验签名。

当前 RAW 支持依赖内嵌预览或 macOS 系统支持，不包含完整显影流程。大图预览最长边为 4096 像素，暂不提供像素级缩放。
